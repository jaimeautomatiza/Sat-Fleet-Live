You can add a free, live ISS tracker to any website by pasting two lines of HTML. The SatFleet Live widget shows the International Space Station moving in real time, on a flat world map or on a 3D globe, with its altitude, speed and coordinates updated every second. There is no sign-up, no API key, no cookies and no advertising.

It works on WordPress, Blogger, Wix, Squarespace, Google Sites and any other platform that lets you add custom HTML. Choose your options below, copy the code and paste it where you want the tracker to appear.

How to Add the ISS Tracker to Your Website

The steps are the same everywhere: find the option that lets you insert your own HTML, paste the code and save. On the most common platforms:

  • WordPress: in the block editor, add a Custom HTML block where you want the tracker and paste the code.
  • Blogger: switch the post editor to HTML view and paste the code, or add an HTML/JavaScript gadget to show it in your sidebar.
  • Wix: add an Embed Code element (Embed HTML), paste the code and resize the box.
  • Squarespace: add a Code block to the page and paste the code.
  • Google Sites: choose Insert, then Embed, open the Embed code tab and paste the code.
  • Notion and similar tools: use their embed block and paste only the address, https://satfleetlive.com/embed/iss.html for the 2D map or https://satfleetlive.com/embed/iss-3d.html for the 3D globe.

If your platform removes iframes from posts, look for a separate HTML or embed element. Most website builders have one.

What Does the Widget Show?

The widget shows the current position of the ISS, together with its path: the path it has followed over the last 45 minutes and the path it will follow over the next 90 minutes, which is roughly one full orbit. A small panel displays its altitude, speed, latitude and longitude, updated every second.

It comes in two versions. The 2D map draws the ground track on a flat map and is the lightest option. The 3D globe shows the station and its orbit around a satellite view of Earth, the same globe used in the full tracker. In both, the view follows the station as it moves; visitors can zoom and drag freely, and a button brings the view back to the ISS. The position is calculated in the visitor's browser from the latest orbital data for the station (NORAD catalogue number 25544), the same method used by the full SatFleet Live tracker. If you want to know more about the numbers it shows, our guide Where Is the ISS Right Now? explains the station's speed, altitude and ground track.

Does the Widget Use Cookies or Slow Down My Site?

The widget sets no cookies and includes no analytics, tracking or advertising, so it does not add anything to your cookie banner. The map and satellite imagery are loaded from Esri, and the orbital data comes from SatFleet Live's own server, which keeps it cached so the widget loads quickly. The 3D version also loads the CesiumJS globe library from cesium.com.

The code includes loading="lazy", which tells the browser not to load the widget until a visitor scrolls near it. That way it does not slow down the rest of your page. The 2D map is light and works well anywhere, including sidebars and pages read mostly on phones. The 3D globe is more spectacular but noticeably heavier and needs a device with 3D graphics support, so it is best for a large, featured spot on the page.

Yes. Besides the ISS, the widget can follow China's Tiangong space station and the Hubble Space Telescope: choose them in the Object option above.
